# Data

## Source

**Bank Marketing** dataset, UCI Machine Learning Repository (dataset ID 222).
https://archive.ics.uci.edu/dataset/222/bank

**Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0).
https://creativecommons.org/licenses/by/4.0/

**Citation:** Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Dataset].
UCI Machine Learning Repository. https://doi.org/10.24432/C5K306

**Introductory paper:** S. Moro, P. Cortez and P. Rita. *A data-driven approach to predict the
success of bank telemarketing.* Decision Support Systems, 2014.

## Files

- `bank-additional-full.csv`: the original file as downloaded from UCI, unmodified. It has 41,188
  rows and 21 columns (20 inputs and the target `y`), separated by semicolons, and is ordered by date.
- `bank-additional-clean.csv`: **not included in the repository.** It is generated by
  `src/clean_data.py`, which removes 12 exact duplicate rows and adds four columns:
  `original_row`, `subscribed`, `previously_contacted` and `pdays_recorded`.

To recreate the cleaned file, run `python src/clean_data.py` from the project root.
